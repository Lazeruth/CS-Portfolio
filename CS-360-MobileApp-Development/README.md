### Mobile Application Development: Weight Tracker

*A functional Android application demonstrating user-centered design, local database management, and iterative development.*

---

---

**Project Overview & Goals:**
The primary requirement of this project was to develop a basic weight tracker application that addresses the needs of users monitoring their personal health. The application allows users to securely create a password-protected account, log their daily weigh-ins, and set a target goal weight. To encourage continued user engagement, the application utilizes background processes to automatically send a congratulatory SMS text message once the user successfully reaches their target goal. 

---

**User-Centered UI Design:**
To fully support these user needs, the UI required specific foundational screens. The design successfully keeps the user in mind by prioritizing simplicity: a straightforward login screen, a secure backend database for password management, and a primary dashboard that displays historical weight entries in a clear, highly accessible list format. 

---

**Development Strategy & Testing:**
My approach to coding the application relied on establishing the structural framework first, and then systematically coding the logic for each framework module. Initially, I reserved functional testing for the end of the development cycle, which resulted in deeply buried issues that were difficult to track down. This process revealed a critical technical lesson: it is essential to test iteratively after coding each individual framework to identify and resolve bugs quickly, a strategy I will carry into all future software projects.

---

**Innovation & Core Competencies:**
Significant innovation was required during the active development phase. Overcoming unexpected technical roadblocks to ensure the functional application matched the intended user experience required thinking outside the box and adapting the original design constraints. Ultimately, the backend development component of this project stands as the most successful demonstration of my technical skills, specifically in architecting the local SQLite database and executing the core object-oriented programming to bring the application to life.
