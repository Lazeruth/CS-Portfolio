### Corner Grocer Sales Velocity
**Fictional Grocery Store Sales Tracker**  
A C++ application designed to read daily item purchasing records from an input document (`CS210_Input_File.txt`) and calculate the sales frequency of each item. This tool helps management identify purchasing trends to optimize store layout and inventory tracking. 
*(Source code and project files are located in this root directory).*

### [Analysis and Design: ABCU Course Advising Program](./analysis-and-design/)
**Data Structures and Algorithms**  
This project is a C++ command-line application designed to support academic advisors at ABCU. It loads a full course catalog from a CSV file into a Binary Search Tree, providing advisors with a fast and efficient tool to list all courses in alphanumeric order and look up specific course details, including prerequisites.
