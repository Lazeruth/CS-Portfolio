## Repository Contents

### [Feline Diabetic Carb Calculator](./carb-calculator/)
**Practical Health Management Script**  
This script was originally developed as a practical tool to calculate the carbohydrate percentages in various brands of cat food. I built this to carefully manage the strict dietary requirements for my cats, Louis and Ava, following a feline diabetes diagnosis. It serves as a great example of using Python to automate real-world, everyday problems.

**How to run this script:**
Open your terminal or command prompt, navigate to the script's directory, and execute the file using Python:
```bash
cd Python/carb-calculator
python CarbCalculatorCatFood.py
```

### [Escape Velocity: Text-Based Adventure](./escape-velocity/)
**Interactive Console Game**  
A text-based adventure game developed as a foundational computer science class project. This program demonstrates the use of game loops, complex conditional statements, dictionary mapping for room navigation, and inventory state management within a console environment.

**How to run this game:**
Open your terminal or command prompt, navigate to the game's directory, and execute the file using Python:
```bash
cd Python/escape-velocity
python "PyGame Escape Velocity.py"
```
